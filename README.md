# DoLBridge

**让 AI 自己在《Degrees of Lewdity》里玩。**

装一个 mod，填一个 AI 接口地址，点「开始」——AI 就会自己上课、打工、赚钱、应对遭遇，你在游戏里随时能看它在想什么、在干什么，也能给它下指令、写计划。

> 你不需要会写代码。会写代码的部分放在文末。

---

## 一、安装（3 步）

1. 下载 **[DoLBridge.mod.zip](https://github.com/kagarikeyfans/DoLBridge/releases/latest/download/DoLBridge.mod.zip)**
2. 把这个 zip 放进游戏的 `mods` 文件夹（或者用 ModLoader 的「安装 mod」直接选它）
3. **刷新游戏**（按 F5）

刷新后，游戏画面右下角会出现一个小浮窗 —— 那就是 AI 面板。

> 用最新版：本文所有链接都指向最新 Release，出问题先确认版本号是不是最新。

## 二、准备一个 AI 接口

AI 不是游戏自带的，需要你接一个**大模型接口**（就是那个聊天 AI 的接口）。

- **推荐 DeepSeek 官方**：注册后在后台创建一把 `sk-` 开头的 **API Key**，充值几块钱就能玩很久
  （官方接口允许浏览器直接调用，装完 mod 就能用）
- 浮窗里的 **配置 → API 配置**，把三项填上：
  - **Base URL**：`https://api.deepseek.com`
  - **模型名**：`deepseek-chat`
  - **API Key**：你复制的那串 `sk-...`
- 点「保存」，再回到「总览」点 **▶ 开始**

> 费用参考：AI 每一步大约几分钱，玩一小时通常不到一块钱。钱是从你的接口账户扣的，和这个 mod 无关。

## 三、面板怎么用

| 分页 | 用来做什么 |
| --- | --- |
| **总览** | 点开始/停止 · 写**计划** · 看/改 **日记** · 看 AI 当前在做什么 |
| **对话·思考** | 像聊天一样给 AI 下指令（比如"今晚回家睡觉"）· 看它的思考过程 |
| **配置** | AI 接口设置、运行参数（都有一句话说明，不懂就别改）|

**计划**很有用，比如写：

> 白天上课、打工赚钱还贝利房租；周一晚上 21 点停下来做阶段总结。

AI 到达你写的时间/条件时会自动停下，并给你一份总结。
（计划、日记都是**改完点「保存」才生效**）

**日记**是 AI 自己写的记录（经验、教训、人际关系）。它自己往里加，你也可以改。
**每个会话有自己的计划和日记** —— 「会话」相当于一个存档槽，互不干扰。

## 四、常见问题

**点了开始，AI 不动？**
看浮窗第一行的小圆点：🟢 表示连上了。⚪ 表示没连上——刷新页面再点开始。
还是不动就检查「配置 → API 配置」三项填对没有、账户里还有没有余额。

**会不会覆盖我的存档？**
不会。AI 只往**当前会话对应的那一个存档格**里存（默认会话 → 存档格 1，会话 2 → 存档格 2），不会碰其它格子。

**弹出一个报错框？**
先升级到最新版（旧版本填输入框时会触发游戏报错框，最新版已修）。
如果还有，把报错内容截图发到 Issues。

**提示连不上接口 / 被浏览器拦住（CORS）？**
换个允许浏览器直连的接口（DeepSeek 官方可以）。或者用进阶玩法里的「外部驱动」。

**AI 说的话我看不懂 / 想让它改风格？**
在「对话」里直接说，比如"以后回复简短点，只说做了什么"。

**能不能中途插手？**
能。随时在「对话」里下指令，AI 下一步就会看到；点「停止」它会立刻停下（记忆保留，再点开始接着玩）。

## 五、隐私

- 这个 mod **不含任何密钥**，也不会把你的游戏内容发给任何人
- 游戏状态只会发到**你自己填的那个接口地址**
- API Key 只存在你自己的浏览器里（换电脑需要重填）

## 六、免责

仅供学习与个人娱乐使用，请遵守游戏原作者的使用条款。
使用第三方 AI 接口产生的费用与风险由使用者自行承担。

# 以下是给会写代码的人看的

## 它是什么

一个**把游戏界面结构化成 JSON** 的桥接层：AI 读 JSON 决策 → 桥接层派发**真实 DOM 点击** → 游戏行为与手动玩完全一致。
不修改游戏变量、不写存档、不写死任何第三方接口。

## 仓库结构

| 路径 | 说明 |
| --- | --- |
| `dist/DoLBridge.mod.zip` | 发布包：装进 ModLoader 即用（含页面内 Agent）|
| `dist/DoLBridge-tools.zip` | 外部驱动 + 自检脚本 + 启动调试浏览器的 bat |
| `mod/` | Mod 源码（`DoLBridge.js` / `boot.json` / 详细 API 文档）|
| `tools/` | 外部 Node 驱动源码 |

## JS 接口速查

```js
DoLBridge.observe()                  // 画面：passage 正文 / 可点动作 / 表单 / 战斗部位 / 状态
DoLBridge.step(i)                    // 点第 i 个动作并等待稳定
DoLBridge.setForm(i, value)          // 填输入框 / 选下拉 / 勾选框（键盘事件用 KeyboardEvent）
DoLBridge.setCombat({leftaction: 1}) // 战斗按部位选动作
DoLBridge.sidebar() / vitals()       // 时间·地点·钱·体征 / 百分比体征
DoLBridge.look() / worn() / wardrobe() // 穿着 / 分部位穿戴 / 衣柜界面
DoLBridge.save(slot) / load(slot) / canSave()
DoLBridge.plan() / setPlan() / notes() / setNotes()  // 计划 / 日记（每个会话独立）
DoLBridge.agentConfig({...})         // 运行参数
DoLBridge.embedded.start() / stop()  // 页面内 Agent
```

完整文档见 [`mod/README.md`](mod/README.md)。

## 外部驱动（接口被 CORS 拦住时）

```bash
node tools/agent.js --port 9222 --interval 900 --out ./agent-out
node tools/check.js --port 9222          # 6 步自检：端口→页面→mod→接口→驱动→游戏
```

游戏需以 `--remote-debugging-port=9222` 启动（见 `tools/启动调试浏览器.bat`）。
驱动在线时页面内 Agent 会自动让位，两者不会抢操作。
